# ForceAutoRotate

スコープ内のアプリを強制的にセンサー自動回転にする LSPosed モジュール（Modern Xposed API 102）。

- 対応：API 102 対応フレームワーク（LSPosed 等）、Android 8.1 以降
- ダウンロード：Releases の ForceAutoRotate-v2.1.apk
- 使い方：インストール後、LSPosed で有効化してスコープに対象アプリを選ぶ

BOAT RACE アプリ用に作成。
